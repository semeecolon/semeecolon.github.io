변동성 분석기

네이버 해외증시 API(api.stock.naver.com)에서 일별 종가를 불러와 일일 수익률(%) 표준편차와 정규분포 근사 그래프를 계산합니다. 브라우저에서 직접 API를 호출하므로 인터넷 연결만 있으면 별도 서버 없이 이 파일 하나로 동작합니다.

빠른 기간
종목과 기간을 선택하고 조회하기를 누르면 여기에 결과가 표시됩니다.
계산 방식 — 일일 수익률(%) = (당일종가 − 전일종가) / 전일종가 × 100. 표본표준편차(n−1) 사용, 연환산 변동성 = 일일 표준편차 × √252.
데이터 출처 — 네이버페이 증권 해외증시 시세 API. 종가 기준이며 실시간 데이터가 아닙니다.
참고 — 이 API는 네이버가 자사 웹페이지용으로 제공하는 비공식 엔드포인트라 브라우저에서 직접 호출하면 403으로 막힐 수 있습니다. 이 경우 자동으로 공개 프록시 4곳 (corsproxy.io → allorigins.win → thingproxy → codetabs)을 순서대로 시도하며, 상태 메시지에 어떤 경로로 성공했는지 표시됩니다. 모두 실패한다면 잠시 후 다시 시도하거나, 파일을 file://로 바로 열지 말고 python -m http.server 같은 로컬 서버로 띄운 뒤 http://localhost:... 주소로 접속해보세요 — 브라우저에 따라 file:// 직접 실행 시 요청이 더 엄격히 제한되는 경우가 있습니다.
