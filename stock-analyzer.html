      ⚠️ 본 분석은 통계적 평균회귀(Mean Reversion) 원리 기반입니다. 추세가 강한 종목은 과매수/과매도 구간이 장기간 지속될 수 있으며, 투자 결정 시 다른 지표와 함께 참고하세요.

      변동성 — 일일 수익률(%) = (당일종가 − 전일종가) / 전일종가 × 100. 표본표준편차(n−1), 연환산 = 일일σ × √252.
      편차 — 이동평균(W일)과 모표준편차로 Z = (종가 − MA) / σ. 볼린저밴드는 MA ± 1·2·3σ.
      워밍업 보정 — 이동평균 계산에 필요한 만큼 시작일보다 앞선 데이터를 함께 받아온 뒤 화면에는 요청 구간만 표시하므로, MA100을 선택해도 그래프 앞부분이 잘리지 않습니다.
      데이터 출처 — Yahoo Finance 차트 API. 종가 기준이며 실시간 데이터가 아닙니다.
      참고 — Yahoo는 브라우저 직접 호출을 CORS로 막기 때문에 공개 프록시 4곳(corsproxy.io → allorigins.win → thingproxy → codetabs)을 query1·query2 두 서버에 순서대로 시도합니다(최대 8회). 모두 실패하면 잠시 후 재시도하거나, file:// 대신 python -m http.server 로 띄운 http://localhost:... 주소로 접속해보세요.
